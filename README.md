# سجل الغياب - مدارس أجيال ينبع الأهلية

تطبيق بسيط وآمن لتسجيل غياب الطلاب. جميع البيانات تُحفظ محليًا على جهازك - لا توجد خوادم خارجية.

## ⚡ البدء السريع

```bash
cd absentpro
npm install
npm run dev
```

التطبيق سيفتح تلقائيًا على `http://localhost:3000`

## 📖 الصفحات الرئيسية

| الصفحة | الوصف |
|-------|-------|
| **📊 لوحة التحكم** | إحصائيات يومية وملخصات حسب القسم |
| **👥 إدارة الطلاب** | إضافة وتعديل وحذف الطلاب + بحث وتصفية |
| **✅ تسجيل الغياب** | تسجيل الحضور/الغياب/التأخر مع ملاحظات |
| **📈 التقارير** | تقارير يومية/فترات مع طباعة وتصدير CSV |
| **⚙️ الإعدادات** | نسخ احتياطية وبيانات تجريبية وحذف البيانات |

## 🔒 الأمان والخصوصية

- ✅ جميع البيانات في جهازك فقط (localStorage)
- ✅ لا توجد اتصالات خارجية
- ✅ لا يتم تجميع أي معلومات
- ✅ يمكن حذف البيانات في أي وقت

## 🏗️ البناء للإنتاج

```bash
npm run build
```

ستجد الملفات الجاهزة في مجلد `dist/` لنشرها على أي خادم ويب.

## 💡 نصائح

- **جرب البيانات التجريبية** أولاً من الإعدادات
- **احفظ نسخة احتياطية** قبل حذف أي بيانات
- **استخدم البحث والتصفية** للعثور على الطلاب بسرعة
- **صدّر التقارير** إلى CSV لفتحها في Excel
